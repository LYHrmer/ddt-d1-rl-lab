# 56：训练展开跨度的三对初始化验证（执行前登记）

日期：2026-11-01。55C 的全部九点已通过四档局部稳定规则；这为新轨迹上的独立梯度验证提供了可复用规则，不改变 53/55 的原判定。

1. **假设与唯一变量**：53 的八步监督可能不能约束 32 步自由闭环中的累计误差。比较训练 loss 的展开跨度 H=8 与 H=32；两臂共用原 53 完整的 7200 条训练转移、6828 个合法 32 步窗口、采样序列、归一化、ridge 和同 seed 初始化。固定动作监督、七组 loss、模型结构、学习率及裁剪全部相同；仅 loss 取八步前缀或完整 32 步。初始化 seeds 固定 56001/56002/56003，不能用旧 53 模型充当本轮 H8 对照。
2. **预算与时长**：六模型各 1000 次更新、batch64，共 6000 更新及 768 万样本状态步；H32 的计算量较高，本轮比较相同更新次数，不是相同计算量。零新增物理训练数据、零策略更新。预计 2–5 CPU 分钟，整轮 CPU 硬限 600 秒、墙钟 900 秒。新验证 seeds 固定 56301/56302/56303，各 600 步，110/260/410 各取一点，再做 90×32 分支，共 4680 policy / 46800 native / 23400 PD，policy 上限 5000。接口复用已完成的 55 admission，训练配对和失败留档另做轻量单元验证。
3. **独立验证与方向门**：六个模型必须完整，且每对数据、窗口、采样、初始化、ridge/stats 哈希一致。自由闭环预测不输入未来真实状态。先封存新九点预测，再运行全部 ε=`[0.00003125,0.0000625,0.000125,0.00025]` 物理分支；逐点使用 55C 的全网格和单侧稳定规则、两次零分支精确一致、四轮扰动均可见。任一真实参考不稳，则整体 `REFERENCE_UNRESOLVED`，不删点、不换步长。H8/H32 分别要求三模型各九点有效同号，并保留模型 ε=.001、`|AD−FD|≤.1|FD|+1e−4`、导数幅值至少 1e−5 的原自检。全部旧 53 开发/探针与 55C 九点同时回归；方向门还要求旧 53 探针和旧 55C 各自九点全部有效同号，以免两臂同一旧点都错却被“无新增错误”放过。原 53 的较大步长参照和 55C 的局部参照分表报告。
4. **跨度收益判定**：方向通过和 H32 优于 H8 分开。只有两臂数值自检均通过、三对新点有效匹配数差全部 ≥0 且至少一对 >0，且 H32 没把 55C 中对应 H8 已正确的点变错，才支持“本轮三对初始化中方向匹配改善”。全持平即未证明跨度收益；不按单 seed 排名。另完整报告三个配对的 32 步状态七组 loss、每点梯度及误差：新 563xx 和旧 55C 的物理梯度标量取预设四档中心差分的算术均值，报告各档值和归一化绝对误差，不挑最有利参照。旧 53 开发点只有模型数值自检，没有真实差分标签；旧 53 探针仍以原两档差分和原 identifiable 判定单独报告。状态 loss 改善不能替代方向门，也不能据此宣称控制性能改善。
5. **资源、失败与后续**：串行单 CPU、Nice10、所有数值线程=1、MemoryHigh2G/Max3G/Swap0，启动有效可用内存 ≥4 GiB、运行保留 ≥2 GiB。最终权重只取固定第 1000 次更新；任何异常、partial、失配均留档，不覆盖、不续跑、不选较早 checkpoint。源码、数据和冻结身份执行前后核验。此轮不选择控制参数、不跑完整控制性能对照；只有验证结果支持时，才另登记下一项实验。

归一化绝对梯度误差固定为 `abs(g_model - g_reference) / max(abs(g_reference), 1e-5)`；均值只用于全部九点参考有效的完整集合，参考未定时总体均值为空并保留各点原始值。

本轮回答的是固定动作监督跨度是否改善自由闭环梯度。它没有直接监督动作 Jacobian，不能预设成功。源码与输入哈希绑定在 `docs/experiments56/paired_horizon56_preregistered.json`；48、冻结源和 runtime v27 保持不变。
