# 55：新轨迹验证观测前向、模型反向的梯度估计器

活动目标要求实际解决方向可靠性与数值稳定性。54已稳定数值自检，但自由展开的方向仍有反例；本轮检验一种可用于离线更新的估计器，不宣称改好了原世界模型的自由预测。

唯一方法变量：自由展开模型梯度 vs 固定θ=0观测轨迹校正后的梯度。两边共享54双精度图、三个53完整模型、完整25固定actor、33整形、损失、32步跨度、ε与全部原门槛。模型/策略网络新训练更新均为0。观测轨迹只能作为离线梯度输入，实际控制器只使用固定actor加最终标量θ。

正式上限15000策略步，计划最多14328；加准入实际最多14552。正式CPU600秒、墙钟900秒、产物128MiB上限。Nice10、单CPU/线程、MemoryHigh2G/Max3G/swap0，有效内存≥4GiB稳定10秒才启动，运行保留≥2GiB；全程重任务串行。

数据隔离：旧53 probe已用于诊断，不能当新最终集。旧dev只用于选θ。新55301/2/3基线轨迹是方法的输入，同一数据同时提供给两估计器；扰动标签不进入ObservedRollout API、校正或提案。新模型预测先封存，再运行±.005/±.01和重复零θ分支。新55401/2/3仅用于条件完整控制评测，不根据其结果重选θ。每个seed结果全部公开，不挑最好模型。

每拍校正`ref_next−F(ref_state,ref_action)`只算一次并detach，所有θ分支共用。所有θ=0状态、动作、观测、滤波与Teacher最大偏差须≤1e-10；不额外对校正结果作四元数投影，范数偏差报告保留。实际控制和真实资格评测仍用原float32固定actor与冻结真实环境；新double只用于离线梯度。

失败/partial留存，第一条基线提前失败即停止后续采集，不覆盖不续跑；完整运行到拒绝分支可以标COMPLETE，但candidate_accepted保持false。即使方向验证通过，原自由展开模型的偏差与观测估计器的幅度误差仍单独报告，不能以此宣布整个活动目标完成。
