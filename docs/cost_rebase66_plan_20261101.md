# 66：固定自由传播敏感度，只重定位代价求值基点

64的注册首拍yaw方向改善已确认，65显示单拍及多拍总代价仍可反号。代价导数是代价局部权重与自由传播敏感度共同作用的结果，不能从某一分量偏小直接认定动力学Jacobian错误。本轮只区分这两类影响，不增加训练或修改控制。

1. **假设**：固定模型的预测值偏差改变了代价局部权重，是部分方向错误的来源。**唯一变量**：代价函数求值基点由模型自由轨迹移至真实θ0基线；模型、actor、历史和状态/动作对θ的敏感度保持。**预算**：固定64的六个最终模型×全部九个643xx点，使用已有32拍基线。**判定**：偏移只在θ0计算并detach，在θ0及±0.001共用；真实未来状态和动作不得进入模型或actor。逐拍代价在重定位θ0时必须精确恢复物理基线。**预计时长**：约10秒。
2. **假设**：此次干预确实只改变代价局部权重。**唯一变量**同上。**预算**：全部54点保存自由与重定位的32拍、六代价分量及全部前缀；每点对自由状态/动作与代价求值状态/动作做同一θ的JVP及固定±0.001差分。**判定**：敏感度不变；自由路径的θ0 trace、标量成本/AD/FD及65已存导数按固定abs1e−10＋rel1e−10恢复；分量和恢复总量。全部前缀自检沿用0.1|FD|＋1e−4，方向幅值门≥1e−5。失败保留原始数组和partial，不重跑。**预计时长**：约20–60秒。
3. **假设**：在同一参考集上比较前后方向，可判定代价求值偏差是否足以解释具体错误。**唯一变量**不增加。**预算**：完全复用65全部四尺度物理参考、六项各32前缀资格；零新物理、零模型/策略/控制更新。**判定**：逐点报告已知错误是否纠正、原正确点是否退化及幅值变化，不用净计数掩盖退化。任何未知参考仍未知，尤其64301/110 H32；小分量不按裸符号记错。若错误在重定位后仍存在，则代价基点修正不足以解释该点，后续再检查真实轨迹上的联合Aδs＋Bδa；即便纠正也仅支持离线诊断，不证明可部署修复。**预计时长**：数秒。
