# SuperMimic 方向与本仓接口：51 离线小验证

2026-10-30。关联 wheel 仓的[运行前协议](https://github.com/LYHrmer/wheel-legged-control-lab/blob/main/docs/world_model51_preregistration.md)。

可以借鉴 [SuperMimic](https://supermimic.github.io/) 的“从轨迹学习动力学，再用模型支持策略优化”方向，但本轮只验证最前面的短时预测前提。所有数值实验在 wheel 仓独立脚本中完成，D1 本仓没有新增训练、仿真或模型替换。

| 环节 | 当前可复用基础 | 仍需单独验证 |
|---|---|---|
| 动力学数据 | wheel 47 的显式 pre/post 状态、控制力矩与执行器逐步记录 | 同模板时间留出之外的数据、噪声/延迟执行器、未知地形 |
| 小模型 | 固定线性预测器加一个 2×64 tanh 残差；三个初始化、固定预算 | 闭环可用性、长时误差和模型梯度可信度 |
| 策略优化 | 保留现有 CPU 协议、课程和奖励作为基准 | 通过模型的策略反传、critic、奖励/终止建模；本轮均未实现 |
| D1 导出 | 现有 PPO→ONNX→C++34 推理链 | 新策略的 627D 输入、16D 输出、历史窗口、参考整形及完整闭环资格 |

wheel 这次模型使用 45D 物理状态、16D 安全力矩和 4D 地形标识，控制周期为 0.01 秒。D1 的 C++34 路径使用 627D 策略输入（57D 当前观测与 10 帧历史）、16D 策略输出，策略周期为 0.02 秒；动作语义也不等同于力矩。不能将该动力学模型当作可直接导入 `actor_server34` 的策略，不能将 wheel 的预测指标当作 D1 闭环指标。

`tools34/replay_cpp_reference34.py` 可复核既有输入/输出及参考整形的一致性，但不验证新策略在物理闭环中的效果。原资格和性能结论仍见 [C++34 结果](cpp_reference34_results_20261018.md)与[使用说明](cpp_reference34_usage.md)。

小验证固定 24 个完整回合，train/validation/test 各 8 回合；只有一个源策略训练 seed。三个模型初始化必须全部满足预注册门槛：8 步速度预测误差比值 ≤0.90、1 步 ≤1.00、各地形 8 步 ≤1.05。不通过就停止，不据结果修改课程、奖励或策略。本轮不复现论文的 GPU 并行训练，也不引入上游机器人资产或权重。


## 实际结果与决定

[wheel 51 结果](https://github.com/LYHrmer/wheel-legged-control-lab/blob/main/docs/world_model51_results_20261030.md)已经完成：3/3 模型各执行 2000 次更新，0/3 通过。一步 NRMSE 从 0.245118 降为三初始化平均 0.208857（−14.79%），八步从 0.649480 升为 0.786479（+21.09%，极差 0.063173）。三个初始化的八步恶化分别为 27.43%、17.70%、18.15%，全数未达 ≤0.90 的改善门槛。

实验 CPU 25.10 秒、组内峰值 0.924 GiB；新增物理步和策略更新均为 0。数据是单 PPO 流的相同课程模板时间留出，初态重复且使用 oracle 状态输入，不能称为独立环境或噪声泛化验证。全部原始数据和模型保留；没有失败后调参或重试。

因此本轮停止进入策略训练，不向 C++34 导出候选。尚未解决多步误差增长的原因、策略梯度可靠性和闭环控制收益。完整 SuperMimic 的适用性仍未被本轮判定；本轮只拒绝这个具体离线残差模型。现有展示策略、参考整形与资格不受影响。
