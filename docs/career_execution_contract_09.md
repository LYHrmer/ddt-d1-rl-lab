# 合同 09：熵奖励是不是 8 倍训练里动作噪声上涨、前进退化的原因

**状态：已登记，待由 release 回执冻结；未执行。** 冻结之后本文的预测、阈值、预算与停止规则不得修改，修改须新建合同。2026-10-16 由用户授权开启并给出训练预算。

## 1. 要回答的问题

合同 08 把 03d 的训练放大到 8 倍，资格仍是 1/3。训练过程复盘（回执 `scale08_training_replay_01`，0 物理步，重放已逐回合与真实环境核对）查明：

- 动作噪声 std 在 1× 附近约 0.356，此后持续上涨，最后 1/4 训练的平均值 0.676，结束时 0.76；
- 向前行驶段内的提前终止，在 0.25–0.5 与 0.5–0.75 两段各为 8 次、5 次，最后 1/4 跳到 43 次，同期转向变好；
- 训练指令符号平衡，所以方向偏置不来自指令。

PPO 的损失里有一项熵奖励（系数 0.005），它直接奖励更大的 std。**本合同只问一件事：去掉这一项，std 还会不会上涨、前进还会不会退化。** 只改熵系数，其余与合同 08 完全相同。
