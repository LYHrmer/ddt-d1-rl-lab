## 冻结的03d命令调度

新增独立 `task03d.py`、`pilot03d.json`，继承03c任务/fast检查。**所有03c奖励数值与公式、actor接口/历史、reset、终止、物理、动作尺度/限幅、PPO网络/优化器/探索参数都不变。** 不加入线速度真值观测、PID、动力学前馈、teacher或动作后处理。

仅对训练命令生成采用以下调度；manual command及固定eval序列仍优先、完全不走训练调度。每episode仍1000 policy ticks/20s，首50 ticks精确零令。只使用该episode原有独立 `_command_rng`；一次性生成完整调度，之后按episode tick取对应段，不使用未来状态/动作/奖励。所有区间左闭右开，整数随机范围均包含两端。

1. 模式以.5/.5概率选择平移或转向；初始符号s独立等概率±1。
2. **平移模式**：A~Uniform[.1,.3]m/s，D~整数[200,300]ticks，G~整数[100,150]ticks。依次为：零50 → `(vx=s*A,wz=0)`持续D → 零G → `(vx=-s*A,wz=0)`持续同一个D → 零至tick1000。
3. **转向模式**：A1、A2独立~Uniform[.1,.3]rad/s；D1、D2独立~整数[100,150]ticks；G~整数[100,150]ticks。依次为：零50 → `(vx=0,wz=s*A1)`持续D1 → `(vx=0,wz=-s*A1)`持续同一个D1 → 零G → `(vx=0,wz=-s*A2)`持续D2 → `(vx=0,wz=s*A2)`持续同一个D2 → 零至tick1000。
4. 所有段vy=0。模式内正负命令持续时间与幅度成对一致；两种模式的运动合计400–600ticks，零令占40–60%、期望50%；每个完整episode必有两次运动→零，转向模式还有两次符号反转。末段零令至少200ticks/4s。动作时长与幅度随机，不复制开发评测的2/5/8s边界。

这是一个命令课程修订：不再声称训练覆盖原随机混合vx/wz任务；其资格范围仍是既定三条平地纯动作任务。正式B/R/M若获准，也必须共同使用此相同课程，延迟处理是唯一实验臂差异。
