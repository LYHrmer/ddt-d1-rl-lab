## 拟沿用的预测和后续顺序

原 09 阈值保留：Q1 最后 1/4 平均动作 std < 0.45；Q2 最后 1/4 前进驱动段内提前终止 ≤ 15；Q3 最终资格至少 2 项；Q4 forward_stop 完整 12 s 不跌倒；Q5 只描述驱动末秒双向速度。基准仍是合同 08 的同种子 8 倍训练。

Q1/Q2 都成立，仅支持本种子的“去熵后噪声与前进退化同时改善”；Q1 成立而 Q2 不成立，说明压低噪声不足以改善前进；Q1 不成立，则熵奖励不是 std 上涨的主因。单变量去熵并未独立操纵 std，因此即使同时改善，也不把这当作噪声中介因果的单独证明。Q3/Q4 独立报告，不改变机制判读。

顺序为：零积分静态检查 → release → E0 → 正式训练/E1 → 单样本新导出入口 → 64 例 C++ 黄金比对（导出通过时）→ 冻结评测器三任务 → 离线训练回合重放 → 判定与总账。导出容差仍为 `1e-6 / 1e-5`；若导出失败，保留 FAIL、跳过 C++，按事前规则用同一最终 checkpoint 评测，部署数值链记未验证。任何结果都不放行正式三臂×三 seed。
