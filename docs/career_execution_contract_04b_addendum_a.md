# Contract 04b 附录 A：零轮动作刹停距离的直接测量

2026-10-11 登记，在该测量执行之前。本附录**不新增训练**，不改动 04b 的任何冻结输入、门槛或预注册预测，也不改写 04b 的失败判定（假设 REJECTED、资格 0/3、1 次跌倒）。

## 1. 为什么需要这次测量

04b 的预注册判定落在合同第 8 条明确写出的那个分支上：

> 若同时 P2/P3 成立（即轮动作确实被压到近零）而 P1 仍不成立，则 G6 的接口算术本身有误，**必须重新测量刹停距离而不是继续调奖励**。

实测（`pilot04b_prediction_verdict_01`）：

| 判据 | forward | reverse | turn | 判定 |
|---|---:|---:|---:|---|
| P2 零令 11–12 s mean(a²) < 0.02 | **0.00099** | **0.00098** | 0.02364（跌倒） | 完成的两条达标 |
| P3 零令 11–12 s 净轮速目标 std < 0.20 | **0.00188** | **0.00219** | 0.1096 | 完成的两条达标 |
| P1 位移 < 0.05 且 末秒速度 < 0.02 | 0.0753 / **0.00138** | **0.02776 / 0.00256** | 跌倒 | NOT_MET |
| P4 forward 8–9 s 位移 < 0.045 | **0.05280** | — | — | NOT_MET |

轮动作确实被压下去了（相对 03d 的 0.065 与 04a 的 0.174，**降 65–175 倍**；抖振标准差相对 04a 降约 500 倍），但 forward 的停车位移仍为 0.0753 m，且其中 **0.0528 m（70 %）发生在 8–9 s 的刹车窗口**。因此 G6 的"零轮动作 ⇒ 纯阻尼 ⇒ 从 0.1965 m/s 刹停 0.0383 m"必须被直接测量。

## 2. 已有的两条间接证据（均不足以定论）

**证据 A（离线，0 物理步）**：在 04b 自己的轨迹里取"轮动作近零（mean(a²) < 0.002）"的 tick 拟合速度衰减，得 τ = **0.84 s（forward）/ 1.63 s（reverse）**，而 G6 预测 0.195 s，差 **4–8 倍**。
局限：拟合速度区间仅 0.0008–0.022 m/s，远低于 0.2 m/s；且 reverse 在该区间仍有 −0.11 ~ −0.15 rad/s 的持续反向目标，不是自由滑行。

**证据 B（开环探针，350 native，回执 `passive_braking_probe_01`）**：腿动作固定为 0（默认站姿）、轮动作固定 0.46 时，整车在 60 ms 内从 0.457 m 沉到 0.432 m，0.7 s 时倾角 0.284 rad、高度 0.324 m，被**非法体支撑终止**，从未进入干净滚动状态。
结论：G6 背后的"刚体直立、四轮均载、纯滚动"前提在这台机器上**不成立**；默认腿姿在 kp=60 下撑不住 48.15 kg 整车。但该探针未能给出刹停距离。

## 3. 本附录要做的测量

腿由已导出的 04b 策略正常控制，**只把四个轮动作强制为 0**，这正是 G6 的主张本身：

- 入口 `tools04/probe_zero_wheel_braking04.py`
- 新鲜 reset（seed 7001），**不使用任何中途状态恢复**；C++ 运行器对此的守卫未被绕过
- 相位 1：手动命令 vx = 0.2 m/s，策略全 16 维动作，100 ticks（2 s）
- 相位 2：命令切零，**轮动作（索引 3/7/11/15）强制为 0**，腿动作仍取策略输出，65 ticks（1.3 s）
- 记录逐 tick 机体速度、世界 XY、轮关节速度、倾角、高度、策略原始轮动作与实际施加轮动作
- 输出：释放时速度、到 \|v\| < 0.02 m/s 的距离与时间、拟合 τ、与 G6 预测的比值、以及 `zero_wheel_action_alone_meets_gate` 布尔判定

## 5. 结果的使用边界（事前声明）

本测量**只回答一个问题**：零轮动作下的刹停距离是多少。它

- **不是**控制资格试次，不计入 04b 的 Python 资格池或 C++ 部署池；
- **不改写** 04b 的 P1–P4 判定、0/3 资格结果或那次跌倒；
- **不构成** watchdog 验收、地形通过、持续侧移或 1.5 m/s 的任何证据；
- 若结果为 `zero_wheel_action_alone_meets_gate = false`，则 G6 被证伪，后续合同**不得**再以"把轮动作压到零"为路线，必须转向主动刹车或其它机制，并需新的可证伪假设与新合同；
- 若为 `true`，G6 成立，则 04b 失败的原因在于策略**在刹车窗口内并未把轮动作归零**（实测 8–9 s 净轮速目标 +0.4596 rad/s、mean(a²) = 0.02208），后续合同应针对"命令切零后的前若干 tick"而非整个零令段。

两种结果都要原样写入结果文档与交接记录，并明确标注这是**单 seed、单次、仅平地**的工程测量。
