# 74执行计划：完整端点响应与新增通道标签核验

落实[74提案](full_response74_proposal_20261101.md)，使用72原始预测和58/62原始物理端点，零模型/actor/物理/训练调用。旧72控制配对与资格保持原样；这是已见72/73后的诊断，不是新盲测或候选训练。

1. **假设**：72加强yaw监督可能伴随其他响应通道误差增加。**唯一变量**：无，完整读回六模型×四角色×九状态×四ε=864区间、38880个raw45误差标量。真实144区间由六模型共享，不算864个独立真实样本。**预算**：0模型/物理/更新。**判定**：F64原端点重建FD并核缓存；yaw28逐项精确复现原72报告。raw45按原七组及F32物理尺度提升F64计算RMSE，输出不屏蔽x/y或轮相位；全部组、角色、seed保留，不用总平均替代逐组差异。**预计时长**：数秒。
2. **假设**：姿态与高度等物理量的响应差异能帮助判断是否值得新增导数监督。**唯一变量**：无。**预算**共享全部864区间。**判定**：对原F64正负状态先归一化wxyz四元数，再用原逆旋转计算body-vx/vy、gravity-x/y；height为state2。五量分别报告物理单位RMSE，不赋任意共同尺度、不与raw45重复计入总分。body端点FD及全域body RMSE与72闭合。四元数只审计符号半球和范数，不自动翻符号或修改raw45。每通道记录三个seed全部增加是否超出读回容差1e−10+1e−8×control；这仅作方向筛查，不接受候选或放宽原门。**预计时长**：数秒。
3. **假设**：原yaw/body标签资格不能外推到其他输出。**唯一变量**：无。**预算**：全部24训练中心、1080个raw坐标通道、120个五量通道，读取24 response及全部240原branch。**判定**：重复零点精确复现，raw central/forward/backward三种FD从原端点闭合；逐坐标/物理量保留四档、原1e−5幅值、同号、spread≤0.25、单边gap≤0.25及独立失败原因。低幅值、零响应和不稳定不混同，不删通道，也不在诊断坐标重新判69–72。yaw原24和body原48资格必须与旧报告一致。**预计时长**：数秒。
4. **假设**：绑定和中断前缀可避免错误或partial进入结论。**唯一变量**：无。**预算**：CPU硬帽30秒（软28秒）、计算墙钟60秒；监督总墙钟360秒容纳原最多300秒内存准入，预计实际计算不足十秒。**判定**：继承72全部843绑定并新增全部实际读取文件和源码，前后核SHA；必须216完整模型状态、864区间、24训练中心、1080 raw通道完整。新增runtime将TERM/INT/XCPU转失败，finally保留完成前缀与后验核验；用真实合成子进程验证TERM/XCPU，不改旧runtime。失败不重跑、覆盖或续跑。**预计时长**：资源准入加秒级计算，CI另计。

验证没有完整的实际F32 a0条件模型零状态；训练也没有六模型的完整raw45预测缓存。因此74不计算这些缺失的模型单边差分或零点误差，不从free-H1 theta0状态替代，不从zero+ε×FD重构非线性端点。这里只检验中央响应误差，不能据此认定自由H32传播或策略梯度已修复。

验证的新raw45/gravity/height通道在74只做中央差分读回，没有获得完整物理参考资格；三对误差均增加仅指四ε原始误差的描述，不自动构成合格参考上的新缺陷。训练24中心的资格不覆盖验证状态，验证各物理输出的单位仍为其物理单位/θ（gravity为1/θ），训练标签则为/absolute-action，两者幅值不能直接相比较。

所有额外输出仍受原H8状态值损失约束，只有yaw与body-vx/vy有当前直接导数监督；不把其余通道说成完全未训练。七组差异和五量差异分别报告，明确height重复raw45[2]。若未见三seed一致的具体未监督响应缺陷，则不能凭本轮启动全状态JVP候选；即便出现，也需先解决相关训练通道未知并另行预注册单变量候选。
