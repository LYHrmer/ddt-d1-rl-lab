# 已有学习信号的阶段诊断（14）

本诊断只读取已完整结束的 03d、08 训练日志和各自固定资格评测回执，复用 08 已有的训练回合标签与资格判定函数。没有加载策略、读取权重、重新推理或进行物理积分；没有使用 09/10 的部分训练权重。实际运行耗时约 0.22 秒，结果见 [phase_learning14_summary.json](../reports/phase_learning14_summary.json)。报告保存 48 个输入的 SHA256，包含所读日志、原始 NPZ、来源元数据及分析代码。

已有数据支持“完整训练回合的学习过程描述”和“固定资格轨迹的阶段指标”，不支持恢复训练中的逐阶段奖励、阶段暴露时间或失效率。入口固定既有 08 重放 report 与 episodes.jsonl 的 SHA，防止保持长度/回报不变而改写合法方向标签。两者分别为 `a529aaa674567295ef45bee8f8fd537b01fb60e8ecc0c9a7ca56d4a161b9fb25`、`5f97b4766ec77cb5fd1e387c370d71899e51465b7b68f04b48a6e223407a2b01`。二者的分母分别如下。

## 阶段与分母

资格窗口使用半开区间：初始零命令 `[0,2)` 秒；前进/后退驱动 `[2,8)`；左转驱动 `[2,5)`、右转驱动 `[5,8)`；非零命令切零后的 `[8,8.5)`；后续零命令 `[8.5,12)`。25 tick 的切零窗口是本次离线诊断约定，不是新增资格阈值。这里的“静止阶段”仅指命令为零，不代表机器人已停稳。转向的正负反转不计为切零。

速度误差、水平速度、侧向速度、总奖励均值和饱和关节数均值的分母是**该完整计划窗口的 tick 数**；峰值俯仰是该窗口绝对值最大值。原始 `tau_saturation_count` 是一个策略周期内至少饱和过一次的关节数：新字段 `mean_saturated_joint_count_per_policy_tick` 对它取均值，允许大于 1，但不是关节占比，也不是全部物理步的饱和事件总次数。只有整个窗口全部观测到才计算指标；部分窗口保留观测/缺失数，整窗指标为 `null`，完全未观测则为 `NOT_OBSERVED`。不补零、不缩短分母、不把跌倒前缀当完整停车结果。

训练回合的 `early_end_fraction` 分母是相应进度组/课程内**已完成的 Monitor 回合数**。`early_end_segment_counts` 只描述提前结束时所在的末段，不是各阶段进入次数、暴露时间或条件风险。尤其 `middle_zero` / `final_zero` 标签不能区分刚切零与后续静止，故训练逐阶段回报、阶段 tick 数、切零/静止拆分均标 `NOT_OBSERVED`。ledger 的奖励分量和 PPO 指标仍是混合阶段的 rollout 统计，不能分配给单个阶段。
