# 下一轮小训练先校准全身动作对后溜的影响

第 95 轮的三个模型、三个新起点均指对了第一次拟议更新。第 4 拍（0.08 秒），两档参数变化导致的平均驻车偏离差已经被模型高估 4.08～13.55 倍。第 32 拍仍高估 3.29～8.38 倍。这支持先检验世界模型对动作变化的敏感度。现有证据还无法判断改策略结构或改任务奖励是否有益。[45 段验证及逐拍数据](supermimic_policy_direction95_results.md)

1. **采集训练专用的配对样本。** 假设是同一起点的正反动作可以直接量出模型需要学准的差异。唯一变量为沿第 95 轮已封存的参数方向走正一步或反一步。三个原策略分别从全新训练起点 96101～96103 起步，18 段 × 32 拍，上限 576 个原生决策。每对须有共同复位状态和首拍 FIFO，同一真实起点必须有成对且完整的八拍窗口才能进入训练。异常、早停和截尾均保留，无法凑齐三个训练起点则该种子停止。预计接线和核对 20～35 分钟。

2. **仅改变世界模型的训练损失。** 假设是给“动作改变引起的位移差”明确的监督可以改善幅值。三份模型各从第 94 轮同一个父检查点及其 Adam 状态分两臂，两臂使用相同的训练数据、批次、采样序列、学习率和更新次数。对照沿用八拍状态预测损失。候选只增加一个配对位移差损失，权重分别为 0 和 1。每批取 16 个原训练窗口，再取 8 对新窗口（共 32 个窗口）。两臂均用实际施加的动作，从各分支窗口的首状态递推八拍。配对目标为每拍两分支相对各自窗口起点的纵向位移之差。该项取预测差与实测差的均方误差，以本种子全部合格训练窗口的目标均方归一化，分母下限为 (0.01 mm)²。三种子 × 两臂 × 50 次更新，共 300 次世界模型更新、76,800 个模型步。学习率 0.0003、梯度范数上限 1，线性底模、归一化统计与策略均冻结。每个种子按封存的第 50 步验收，有限值或完整性检查失败即登记。预计实现、拟合和核对 25～50 分钟。

3. **盲测新的坡上起点。** 假设是幅值改善可迁移到训练未见过的起点。比较的唯一因素仍为配对损失开关。沿用第 95 轮封存的三个方向，在另外三个复位种子 96201～96203 上评估五档步幅。两套模型共享同一份原生物理答案，先封存预测，再开启原生对照。预算 45 段、1,440 个原生决策、2,880 个模型步、18 次零步幅解析导数计算。沿用原 9 格 18 项、同号及 25% 幅值、安全和正向优于原参数的完整门槛。为归因于新增损失，候选还须在每个训练种子上降低六项斜率误差的中位数，且三个原参数起点的 H32 回报绝对误差的中位数须不高于等预算对照。相对误差分母沿用两数绝对值较大者。任一格早停或非法接触均保留。预计测量、读回和 CI 20～35 分钟。

整轮最多 63 段、2,016 个原生决策、10,080 次伺服、20,160 个物理子步、79,680 个模型步。正式策略更新 0 次。全程使用受限单 CPU 和单环境，入场余量 4 GiB，运行余量 2 GiB，Nice 10、MemoryHigh 2 GiB、MemoryMax 3 GiB、swap 0。第 94、95 轮的原生验证轨迹不参与拟合。通过此轮只支持候选对已封存方向的幅值预测。候选模型自己给出的新策略方向以及首秒驻坡控制，还需要独立原生对照才进入策略训练。
