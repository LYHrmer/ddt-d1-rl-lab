# 复合地形 1.5 m/s 的轮地响应对照方案

第 111 轮有两个能区分原因的观察。三个复合路起点的前 170 拍中，各自不同雷达开关组的机身位姿、速度指令和全身动作完全相同。第 170 拍时最前轮缘仅到 x=1.72～1.76 m，距 2.50 m 坡脚还有余量，车已经偏慢。驶出地形后，前进指令恢复相同，车速差仍然存在。分别检验路面接触表示和车载速度补偿，可以区分两者的作用。最终验收沿用实体台阶、上下坡、交错起伏和停车条件。[上一轮完整测量](lidar_compound111.md#复合路线实测)

## 速度补偿如何工作

原厂网络依然每拍给出 16 个腿轮目标。新增量只作用于它接收的前进指令。50 Hz 下，使用上一拍实际送入网络的前进指令减去四轮编码器速度中位数乘以轮半径 0.087 m，估计持续的跟踪偏差。驾驶请求连续 10 拍相同时才以 0.40 秒时间常数更新，避免把加速过程直接算成稳态偏差。在当前 1.5 m/s 请求下，以验收区间中点 1.5375 m/s 为平稳跟踪参考，补偿范围为 0～0.18 m/s，每拍最多改变 0.0036 m/s。雷达给出的减量继续逐拍执行。记录补偿前后指令、估计偏差、轮速和机身实测速度。评估雷达时在同一拍固定补偿量，复算屏蔽雷达的指令。[候选算法与只读回算](../tools112/velocity.py)

用第 111 轮实际发出的指令和编码器读数逐拍回算，平地三条中央路段的建议补偿中位数都为 0，复合路三条分别为 +0.111、+0.111、+0.124 m/s。停车段三条复合轨迹分别建议 +0.079、+0.082、+0.079 m/s。新指令的真实速度和停车结果需要上表闭环实测，并单独检查车轮滑移对估计的影响。

每段上限为 12 秒、600 个决策、6,000 个物理子步。本方案最多新增 **15 段、9,000 个决策、90,000 个物理子步、1,123,200 次动态射线查询**。不训练策略或世界模型。运动门槛为中央三米均速 1.50～1.575 m/s、各单米 1.425～1.575 m/s、四轮守住车道、四轮分别在台面和出口承重、末半秒每拍水平速率 ≤0.05 m/s、全程无跌倒或非法支撑。平地只考核适用项目。发生资源中断的工况保留预约和回执。原始地形、评分、模型与执行器使用第 111 轮留存版本，所有新跑次单 CPU 串行，沿用 Nice 10、MemoryHigh 2 GiB、MemoryMax 3 GiB、swap 0 和 4/2 GiB 内存门槛。
