# D1 训练世界模型预测第 17～32 拍的动作效果

在三个新起点上，世界模型对策略扰动的收益方向从 **10/18** 项正确提高到 **18/18**，幅值在原定 25% 容差内的从 **4/18** 增至 **10/18**。九组完整验收从 **2/9** 增至 **3/9**。三个训练种子中，两个改善了斜率误差中位数，一个改善了第 16 拍状态误差中位数。两项都要求三个种子各自改善，本轮停在世界模型阶段，策略更新为 0。[事前方案](supermimic_late_response99_proposal.md) · [正式报告](../reports/late_response99.json) · [九组盲测视频](assets/late_response99.mp4)

## 这次训练改变了什么

三份第 98 轮的世界模型各自分成两组，起始权重、线性动力学部分和 Adam 状态相同。每次更新，两组都从复位连续预测 18 条轨迹的前 16 拍，其中六条正、反扰动轨迹继续走到第 32 拍。每一步都输入原生训练轨迹当时实际执行的动作。两组都学习前 8 拍的状态与动作响应，以及第 16 拍的状态。唯一变量是第 17～32 拍的正反两条轨迹有符号位移差是否计入训练损失。两组权重分别为 0 和 1，各更新 25 次，取 Adam 第 200 步检查点。[训练损失](../tools99/loss99.py) · [数据和归一化](../tools99/data99.py) · [预注册](experiments99/late_response.json)

评测沿第 95 轮封存的全身策略参数方向取 −1、−½、0、+½、+1 五档。两种模型从同一物理初态开始，各用自己的预测状态和策略闭环走 32 拍。90 条预测和 18 个原参数导数全部封存后，才在同三个新起点 99201、99202、99203 跑 45 条共享的原生 MuJoCo 轨迹。地形为 4° 上坡，控制目标是驻车，回报取前 32 拍偏离原始驻车点距离的负平均值。实测正向整步相对原参数的平均偏离减少 **0.705～1.006 mm**。这些是两组世界模型共同预测的动作效果。[盲测程序](../tools99/run99.py)

## 按种子验收

每个种子的斜率比较有六项，分别来自三个新起点和两档对称步幅。将模型在原参数处的解析导数与原生中心差分相比，误差为两者绝对差除以较大的绝对值。第 16 拍状态误差沿用七组归一化均方误差，每个种子取 15 条轨迹的中位数。表中顺序均为对照组 → 新损失组。[评分实现](../tools99/score99.py) · [完整判据](../tools95/score95.py)

| 世界模型种子 | 斜率误差中位数 | 斜率同号 | 幅值在 25% 容差内 | 第 16 拍状态误差中位数 | 完整通过 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 94011 | 99.17% → 4.38% | 4/6 → 6/6 | 0/6 → 6/6 | 0.002581 → 0.005666 | 0/3 → 1/3 |
| 94023 | 150.22% → 37.83% | 0/6 → 6/6 | 0/6 → 0/6 | 0.022818 → 0.006561 | 0/3 → 0/3 |
| 94037 | 19.63% → 21.95% | 6/6 → 6/6 | 4/6 → 4/6 | 0.003184 → 0.003427 | 2/3 → 2/3 |

候选正式通过的三组为 94011/99202、94037/99201、94037/99203。其余六组的失败原因分得开。

- **四组幅值高估。** 94023 在三个起点都纠正了方向，但六个导数与原生斜率的比值为 1.476～1.741。比如在 99201，模型预测从 −0.477 改为 +1.252 mm/参数步，原生半步和整步分别为 +0.719、+0.778。94037 在 99202 的两个比值为 1.345～1.351，也超出原有容差。
- **两组末拍非法接触。** 94011 在 99201 的五条原生轨迹全部于第 32 拍出现非轮部位接地，在 99203 仅反向整步发生同类接触。这两组的候选幅值均达标，安全门失败。45/45 条原生轨迹都走到末拍，39 条全程安全，0 次跌倒。所有六条终止记录都保留了末拍数值与标记。

两种模型均保留 45/45 条完整状态预测。候选导数与模型自身差分在 18/18 项满足 25% 容差，与原生差分则为 10/18 项。原生的 18 项斜率全部为正，因此同号结论的适用范围是这三条已知策略方向在本轮新起点上的响应。全套盲测各格的原生回报、模型导数和安全标记均可重算。[公开曲线和标志](../reports/late_response99_curves.npz)

## 新损失具体学到了什么

训练批次上，第 25 次更新前记录的后半段响应损失，对照和候选分别为 1.2459 → 0.0341、3.0608 → 0.0366、0.1612 → 0.0104。另用盲测中已经保存的正反整步轨迹，事后检查相同的物理量。对每条分支取第 17～32 拍相对自身复位点的纵向位移，在每一拍用正向减反向，再计算预测与 MuJoCo 的均方根误差。[逐次训练记录](../reports/late_response99.json) · [可独立重算的坐标](../reports/late_response99_curves.npz)

| 种子 | 新起点的后半段正反整步位移差误差，对照 → 候选 |
| --- | ---: |
| 94011 | 4.289 → 0.298 mm |
| 94023 | 5.436 → 1.829 mm |
| 94037 | 0.983 → 0.866 mm |

每行包含三个新起点、每个起点 16 个观测时刻。这个检查回答了两个已知策略参数设置之间的轨迹差能否预测得更准。用于更新策略，还要估准**原参数处**的一点变化能带来多大收益。94023 的结果说明这两个问题能得到不同答案。若继续排查，优先定位原参数附近的幅值高估，同时检查第 16 拍状态误差的回退。接触动力学与策略反馈各自贡献了多少偏差，仍待分开验证。[三项预注册判定](experiments99/late_response.json)

## 预算与复核
