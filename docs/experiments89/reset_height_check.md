# 89 轮起点测高校验记录

最初的零积分预检在读取原 87 平地时中止。种子 89102 首次重置，前左轮心 x 为 0.165895 m。沿 y=1.20 m 的高度场网格边发出竖直测高射线，MuJoCo 3.3.0 返回同一地形的底面 z=−0.160 m。该位置的平地表面应为 0 m。首个失败单元的轨迹段数、训练更新和物理步数均为零，回执保留在 `evidence/uphill89/preflight_01/`。

在同一 x、横向高度恒定的两个三角形内部独立测高，继续逐点要求误差小于 2 µm。18 个原 87 重置状态的 72 个轮心位置上，原网格边探针有 6 次误判。计入 3 个坡上重置后，新探针 168 次测量的最大误差为 7.35 nm 以内。33 次原起点的初始位姿、速度、动作队列、首个本体观测、历史和待发送的测距包均与第 87 轮逐值一致。坡上重置另外核对了四轮法向间隙。小型原生高度场测试覆盖同一网格边现象。[测高实现](../../tools89/course89.py) · [独立原生高度场回归](../../tools89/check_heightfield89.py)

原失败单元保留独立目录。修正后的几何准入与六段实际短仿真分别在独占单元运行。训练起点、物理接触、策略传感器、PPO 配置及所有判定门槛沿用预注册。场地测高射线只服务于准入检查，训练和评测使用各自原生车载射线。[预注册](uphill_curriculum.json)
