## 2. 已确认的接口与训练资源

当前部署对象来自 `src/ddt_ros2_control/urdfs/d1_description/mujoco/robot.xml`，为四腿四轮、16 个驱动关节。`flat_lab` 使用 `P_V`：12 个腿关节的目标为默认角度加 `0.25 × action`，腿 kp/kd 为 60/1.5；4 个轮关节的速度目标为 `5 × action` rad/s，轮 kp/kd 为 0/0.5。关节顺序为 FL、FR、RL、RR，每腿 hip、thigh、calf、foot。

策略可见的一帧为 57 维：机体系角速度 3、投影重力 3、指令 3、关节位置偏差 16、关节速度 16、上次动作 16；车体线速度和世界坐标不在 actor 输入中。轮位置置零。角速度存在 `0.97 × 新值 + 0.03 × 旧值` 滤波。当前策略输入是本帧及 10 帧历史；`FSMState_RL::update_forward` 在推理**之后**将本帧移入历史，因此历史不应偷偷改成包含当前帧的窗口。进入状态时历史重复初始观测。动作上次值应采用策略坐标顺序，并明确是在限幅前还是限幅后记录。

`workspace2.zip` 确实带 DDT_Lab/NP3O 训练源码，但当前 `DDT_D1_CFG` 指向 `d1_with_g2_combined.usda`，配置加入机械臂和夹爪，rough 配置明确是 78 维观测、23 动作。该包 README 的默认栈为 Isaac Sim 5.1 / Isaac Lab 2.3，默认 4096 并行环境。这些文件不能直接当成本次纯 D1 / 57 维 / 16 动作 ONNX 的精确训练来源。

本机只读检查发现 24 个逻辑 CPU、约15.25 GiB RAM；GPU 为 RTX 5060 Laptop，8151 MiB显存，父代理在宿主实测 PyTorch CUDA 可用且包含 sm_120。默认 Python 3.10 的 torch 为2.12.1+cu130、mujoco为3.12.0、gymnasium为1.3.0、onnxruntime为1.23.2，尚缺stable-baselines3、onnx、jax。C++运行器仍为MuJoCo3.3.0/ORT1.10.0，因此新训练环境必须隔离依赖并固定MuJoCo3.3.0，不能默认用3.12.0物理训练后称模型一致。导出的ONNX须与旧ORT1.10兼容；最终黄金比对以实际C++加载的运行库为准。

已发现的部署实现问题需在新运行器分支中处理：原 FSM 的 `std::clamp` 上下界颠倒且返回值未赋回，但原桥 `MujocoSystem::write` 已对合成 FF+PD 力矩按 URDF/interface 限制夹紧，不能说旧系统完全没有限矩。独立审计确认 URDF 为腿 ±80、轮 ±12 N·m，与 XML actuator force range 相同，而 YAML 的轮20不是实际桥接上限。新训练及部署显式采用80/12并记录夹紧后的最终力矩；qfrc_applied通道不能依靠XML的actuatorfrcrange自动限矩。新旧运行器时基仍有差别，旧轨迹不进入新三臂严格对照。

本轮新接口将动作裁剪到[-1,1]并沿用轮倍率5rad/s，纯滚动目标量级上限约0.435m/s；它只覆盖当前±0.3m/s低速合同，不能据此宣称具备1.5m/s。将来提速需要重新确定轮倍率/约束并另行训练验证。旧flat_lab没有此动作裁剪，不把旧checkpoint直接塞入新接口后当同一基线。

优先覆盖多个可解释难度，例如坡度 5°/10°/15°、台阶 15/30/50 mm、不同幅度起伏路。以上为建议分档，最终几何以根代理生成并冻结的场地清单为准；资产交付时可以调整，任何物理评测启动后不可因结果不理想改几何或门槛。

本阶段不需要跑策略，也不触发后续训练。交付教程应先教用户启动丰富场景、站起、选择 flat_lab、低速控制、停止/蹲下/退出，以及如何读取区块参数；没有验证的地形标为“待测”。

## 4. 阶段 B：零物理接口审计与新运行器

建立机器可读 schema：模型 SHA、关节名与索引、坐标系/四元数约定、观测片段、缩放、历史顺序、动作映射、最终力矩限制、物理/PD/推理周期。默认新训练物理步长 0.002 s，PD 更新每两个物理步（250 Hz），策略每十个物理步（50 Hz）；最终部署必须按仿真时间同步调度，避免墙钟线程与加速仿真混用。PD 在两个物理步之间保持力矩的细节也要与部署一致。

离线 golden fixture 覆盖单位姿态、非零 roll/pitch/yaw、单关节位移/速度、命令边界、动作限幅、历史第一次与第十一次更新、重入/reset、NaN 和维数不匹配。独立计算训练 Python 与 C++ 的观测和动作→力矩结果，不能两边同时调用同一个错误实现后声称一致。浮点误差阈值：观测与力矩绝对误差 ≤1e-5；Torch/ONNX 动作 ≤1e-5（若版本造成更大误差，先调查而不事后放宽）。

命令超时基于单调时钟，默认超过 0.5 s 将请求置零；不因键盘松开而假定已经收到了零命令。记录模型/schema 身份、策略序列号、控制时刻、推理时延和过期动作。NaN、错误输入形状、错误模型身份必须拒绝进入 RL；超时和推理异常执行明确的受限站立/停令回退，回退的稳定性另行有界验证。

训练 reset、部署进入 RL 均清空动作/滤波/历史/延迟队列。时间截断须 bootstrap critic；真正跌倒终止不 bootstrap。训练、验证和测试使用分离的随机流；评测不能推进训练 RNG。

## 5. 阶段 C：适合本机的自训技术选择

采用**原纯 D1 MuJoCo 模型 + Gymnasium 环境 + 标准 PPO**。从随机权重训练，不载入同事 ONNX、不用其轨迹作监督、不导入旧项目 checkpoint。使用固定默认腿姿态和 P_V 执行器是一种显式控制参数化，不是训练成果；教程应解释 PPO 学习的是全部 16 个动作，轮速度和腿姿态修正都来自策略。

优先使用经过验证的 stable-baselines3 PPO，锁定版本后建立新环境；不把旧项目整套环境复制后替换名称。本机 CPU 原生 MuJoCo 以 4 和 8 个并行环境各做一次有界吞吐预检，选择总吞吐更高且内存稳定者，最多8个环境进程。观察进程树USS/PSS和系统可用内存，至少保留3GiB给系统/ROS；低于该值停止增并行度。PyTorch 小 MLP 优先 CPU 单线程；仅当实测更快且 GPU 与版本兼容时使用 GPU updater。不为该闭环安装大型 Isaac 渲染栈，也不在同一轮临时引入 MJX/JAX 后更换物理模型。

Actor 输入为本帧 57 + 历史 570 = 627 维，MLP [128,128]，tanh 激活；输出独立高斯 16 维。Critic 可用相同输入，首轮不加 privileged critic，以减少实现分支。ONNX 导出确定性均值，保留当前观测和历史两个具名输入；部署仍使用同一 57/10/16 契约。若改用特权 critic，必须在正式训练前重新冻结配置且保证任何真值均不进入 actor。

PPO 初始设置：learning_rate=3e-4，gamma=0.99，GAE lambda=0.95，clip=0.2，value_coef=0.5，entropy_coef=0.005，max_grad_norm=0.5，4 epochs，minibatch=256；每轮总样本固定 4096（8 env×512 或 4 env×1024）。样本动作的 log_prob 必须对应原始采样动作；若环境执行时裁剪，buffer 中不可把原始样本悄悄替换成裁剪动作。策略确定性输出和训练执行均使用冻结的 [-1,1] 动作限幅。

训练任务先限为平地低速：vx∈[-0.3,0.3] m/s、wz∈[-0.3,0.3] rad/s、vy=0，20 s episode，包含明确零速片段及起停/转向指令变化。不同时宣称学会侧移、台阶或高速。初始 joint/yaw 小扰动的分布和比例事前写入配置，默认姿态由静态几何确定，任何动态安定/预热均计入物理预算。奖励项需在正式运行前固定：机体系 vx/wz 跟踪、停令速度、姿态/高度偏差、动作变化、能耗与非法身体接触；记录各项原值、权重和总贡献，禁止只看总 reward 判断能力。

阶段 A 的丰富场地保留用于后续训练扩展和独立测试；本轮主要因果实验保持平地，避免同时改地形课程、奖励和延迟后无法归因。

## 6. 一项主要改进与 3-seed 消融

假设：训练时的动作延迟随机化能提高命令改变和停车时的延迟鲁棒性。只改变动作通道的延迟分布，观测、网络、奖励、模型、优化器、命令/重置分布和总步数相同。

| 实验臂 | 训练动作延迟 | 解释 |
|---|---|---|
| B 基线 | 固定 0 ms | 无额外延迟训练 |
| R 改进 | 每 episode 均匀抽取 0/20/40 ms | 延迟随机化 |
| M 消融 | 固定 20 ms | 保持随机化臂的平均延迟，检验随机性是否必要 |

延迟作用于完成限幅的整条 16 维动作，每 20 ms 策略 tick 更新 FIFO；不延迟命令，不延迟 actor 观测，不额外改变 PD 采样。延迟队列的 reset 初值为零动作。三臂都保留 10 帧历史，不把“取消历史”和“取消随机化”混成同一消融。

正式训练 seed={11,23,37}，每臂每个 seed 从头独立训练，9 次运行。相同 seed 的初始化与外生场景流配对；延迟 RNG 使用独立流，避免随机化臂多抽几个随机数就改变全部命令序列。按固定最终步数 checkpoint 比较，不用测试集选 checkpoint。不选表现最好 seed 作为整体结果；展示全部 9 条训练曲线和每个 seed 的测试值。

## 7. 分阶段预算和停止规则

预算计数单位统一：1 个 environment transition = 1 个策略控制周期 = 10 个 MuJoCo native 物理步（reset/安定等额外物理步另加实计）。并行环境数不改变总样本数。所有试运行和失败也占预算。

| 阶段 | 上限 | 放行条件 |
|---|---|---|
| A 场景 + B 离线审计 | 训练 0、物理步 0 | 静态场景与接口 golden fixture 通过 |
| 吞吐预检 | 两档 env 数合计 ≤65,536 transitions；墙钟 ≤10 min | 无 NaN/内存增长；实际吞吐、CPU/RAM/GPU峰值已记录 |
| 单 seed 闭环 pilot | seed=101；≤1,048,576 transitions；墙钟 ≤90 min | 导出与离线一致性通过，再做独立 C++ 有界低速试次 |
| pilot C++ 验证 | 最多 3 次，每次 ≤30 s 仿真/15,000 native 步 | 任一异常立即结束该试次，全部记录；不能失败后无限试 |
| 正式 3 臂×3 seed | 候选每次 4,194,304 transitions，共37,748,736；每次墙钟 ≤3 h | pilot 低速闭环通过；正式预算锁定文件已产生 |
| 固定独立评测 | 每模型36个12 s episode；9模型共1,944,000 native步，reset额外步另设≤100,000 | 评测定义/场景seed/模型SHA在首个episode之前冻结 |

正式训练预算的预注册规则：以预检的实测总吞吐 q（transitions/s）估计每次 4,194,304/q 秒，再乘 1.25 留出更新、导出和调度开销；如超过单次 3 h，正式预算改为每次 2,097,152 transitions；若该档仍超过 3 h，则暂不启动多seed，先完成实现/教程并报告计算不足。此选择只由吞吐决定，不能看某一臂成绩后改变。最终预算须写入 `evidence/career_contract_03/formal_budget.json`，9 次运行完全一致。全批最多27 h墙钟，实际用时由吞吐预检估算；各阶段依次放行，本文本身没有启动任务。

pilot 不进入正式三seed统计，也不作为正式初始化。开发期最多两轮修复、共三次pilot；每次仍为最多1,048,576 transitions/90 min，开发期合计最多3,145,728 transitions/4.5 h。每次重新训练和最多三次C++验证单独计数，开发期C++总上限135,000 native步。pilot 未过且有可定位实现问题，先做离线修正；更换奖励/网络/任务难度时必须在下一pilot开始前冻结新的版本，不反复用独立测试集调参。三次后仍未通过则停止扩展、多seed标为未执行，交付代码、失败分析和教程，不能无限补跑。已耗用的pilot/失败预算不得抹掉。没有足够训练预算可以如实得出“未学会”，不能把行为克隆或现成权重补位后称自训PPO。

所有阶段遇到非有限状态/动作、错模型或错关节映射、步计数不连续、GPU OOM、反复数值发散，立即停止该阶段并保留现场。正式运行 hit 墙钟上限时记录 TIMEOUT 与实际步数；不可与完整预算模型作为等预算成功对照。学习差属于真实结果，不是删除 seed 的理由。

## 8. 冻结的独立评测与成功含义

评测使用 0/20/40/60 ms 四档执行延迟；60 ms 为训练范围外压力测试，单独报告。每档使用前进-停止、后退-停止、正负转向-停止三条固定12 s命令序列，各3个重置seed={1001,1002,1003}，每模型36个 episode。具体各段起止仿真时刻在 JSON 中冻结。发令时记录实际仿真 timestamp 和样本 timestamp，不重复合同02的阶段边界误差。

基准名义工况的预设门槛：无跌倒/非法身体承载；前/后进稳定段机体系vx MAE≤0.06 m/s；转向稳定段wz MAE≤0.08 rad/s；停止末1 s水平平均绝对速度≤0.02 m/s、绝对wz≤0.03 rad/s；停止位移≤0.05 m；roll/pitch绝对峰值≤0.20 rad。命令变化后的暂态误差另报，不混入稳定段。世界走廊跟踪不是本轮低层机体速度策略的门槛；若另做世界路径任务，需要独立航向外环和独立指标。

主要误差 J 为每条序列上的归一化vx/wz跟踪绝对误差时间平均，加停止段水平速度绝对值时间平均（各项分母固定0.2，单位按配置解释）；未完成episode给固定失败惩罚，不通过早跌倒减少积分时长得分。三种指标分量及失败率与J同时报告。R相对B在20/40ms下的跨seed配对J改善中位数≥15%，且0ms名义工况J退化≤10%、失败数不增加，方可称本次改进有效。M用于回答改善来自平均延迟还是随机化；没有达到门槛也必须交付完整负结果。

3个训练seed是统计单元，36个episode不是36个独立训练样本。报告每个seed、均值/中位数、范围或bootstrap不确定性，并明确n=3的限制；不声称显著优越或普遍sim2real提升。

丰富地形的正式通过评测另开专项清单。尤其15mm台阶需真实轮接触、全车包络跨线和台面承载证明；不能因视觉上越过标线或训练reward升高宣称通过。未跑地形一律保留待测标签。

## 9. 运行时与教程最终交付
