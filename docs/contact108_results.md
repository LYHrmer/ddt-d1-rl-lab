# D1 的前轮碰到 3 厘米台阶时，多弯一点前膝会怎样

12 段原生 MuJoCo 闭环都测到了前轮与台阶的接触力，没有一段测到前轮在水平台面承重。独立测量表明，前膝多弯约 0.08 rad 后，机身最多额外下沉 8.39～8.66 mm，前轮中心高度的变化却不到 0.15 mm。三份触阶世界模型的验收为 **0/9**，本轮全身策略更新 **0 次**。[三对独立起点的慢放视频](assets/contact108.mp4) · [关节、机身与接触点读数](../reports/contact108/blind/physical_readback.json)

## 怎样看视频

左屏是冻结的 D1 全身策略，右屏在同一起点运行同一策略。前轮第一次对台阶产生至少 1 N 法向力后，右屏给两个前膝额外加 0.08 rad 屈曲目标，持续 0.32 秒。腿和轮仍由原来的 PD 和轮速伺服执行。三个独立起点按原顺序全部展示。观察前轮贴住台沿时机身前部的下沉，再看轮心有没有升到台面上方。画面取自实际运行的姿态存档，接触窗口以四分之一速度播放。

视频总长 **35.28 秒**。第一对在播放到 **5.44 秒**时触阶，到 **7.48 秒**时右侧机身比左侧低得最多。后两对相同的机身下沉峰值分别在 **19.12 秒**和 **30.84 秒**。橙色区域是台阶，黑色前轮旁的短线帮助观察车轮转动。

## 世界模型学到了多少

这次学习的对象是在固定全身策略下，短时屈膝对前轴运动的局部影响。模型只读取首次接触前已送达的轮速和前膝角，将已知动作延迟与脉冲输入传播 32 拍。三份九参数模型各用相同的三个开发起点训练 100 次。权重封存后才采集盲测数据。预测只读取新起点的触前观测，预测文件封存后才打开两臂位移标签。三个模型共用三个独立物理起点。[模型实现](../tools108/model108.py) · [拟合与损失记录](../reports/contact108/fit/fit.json) · [盲测预测回执](../reports/contact108/score/forecast_seal.json)

## 下一项可区分原因的试验

前轮触阶前到底看到了什么？从实际送达的八束距离出发，按每包的**采集**时刻和原传感器外参把端点投回地形。两个动作臂在分叉前逐拍相同，每对只计一次。六个复位合计 78 包，78 包都有左右两侧的台面回波。624 个有效端点中，521 个落在台面、100 个落在低地面、3 个落在前立面。第一包就看到了台面，但落点离前缘还有 222～654 mm。左右八束首次全落在高处的包，比首次触阶早 0.600～0.762 秒。事后使用仿真位姿和地形真值给回波分类，这些标签没有送给策略。六个复位共享同一处台阶，台阶位置的泛化仍待测量。[开发包回读](../reports/contact108/development/preview_readback.json) · [独立起点回读](../reports/contact108/blind/preview_readback.json)

本轮唯一的动作变化发生在轮子已承重之后。下一项优先验证**机载信号能把前缘定位到多早、多准**。可在存档上只用当时收到的距离、轮速和 IMU 估计提前量，用落台前后过渡、两侧不一致及平地误报检查这种触发是否可靠。得到可用的提前量，再单独改变同一脉冲的时机，保留当前台阶、策略、PD 和评分，测前轮能否先抬高、随后在台面承重。本轮没有比较课程或奖励。AME-2 的地图不确定度可用来标识距离估计中的未知区域。[AME-2 源码对读及离线检验设计](ame2_learning.md)
