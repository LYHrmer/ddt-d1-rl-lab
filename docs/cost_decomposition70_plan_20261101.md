# 70：用保存端点分解69首拍代价方向误差

69的body响应RMSE在三对模型上下降，但新增5个明确代价反号、2个幅值失格，旧五例失败也未修复。70只读已经完成并封存的数据，回答其中**H1**代价偏差的组成；H32档案没有完整正负端点，不能假定能做同样分解。本轮不拟合模型或运行actor，不新增物理、策略或控制更新，不修改69资格。

1. **假设**：响应拟合改善后，代价残差的中点差或割线响应幅值差仍能造成总代价反号。**唯一分析变量**：对固定端点采用预先确定的对称代数分解，无控制或训练变量。**预算**：六模型×27状态×四真实ε，共648对、3888个成本分项；模型ε固定0.001，真实ε固定3.125e−5/6.25e−5/1.25e−4/2.5e−4，全部保留。**判定**：逐分项重建保存的FD差，总代价另加原AD−FD及逐层舍入余项；所有恒等式满足1e−10＋1e−8尺度容差才允许解释。**预计时长**：数秒CPU，硬上限30秒CPU/60秒墙钟。
2. **假设**：中点差主要来自零点差，或来自端点中点相对零点的偏移差。**唯一分析变量**不增加。**预算**：同一648对上保存22个标量残差的零点、中点、割线和全部分解项。**判定**：midpoint项必须重建为zero-point项＋midpoint-offset项，并分别保留有符号数值和绝对量；offset不称曲率估计，zero-point差不称纯模型状态偏差。F32动作量化、夹紧、坐标变换和不同ε都可能贡献这些差异。**预计时长**：与第1项共享读回，增加不超过数秒。
3. **假设**：某些固定成本分项的FD误差在三个初始化上有一致变化，可为下一候选提供方向。**唯一分析变量**不增加。**预算**：全27点主分析，旧56/旧64/新693xx各9点分别报告，六成本项全部列出；所有69 H1失败及新增H1回退均另附。**判定**：每个seed/arm/role按相同点与ε等权计算分项FD MAE，逐对原始差值及全三对数值下降/上升/相等/混合均报告；同时展示舍入余项量级。绝对代数贡献不当作可相加的归因百分比，贡献变小不等于对应机制改善，不据此自动训练或改判69。**预计时长**：报告分析约5分钟，不新增数值预算。

对每个成本残差坐标r，m=(r+＋r−)/2、d=(r+−r−)/(2ε)，平方成本差分为2wmd。模型与真实差分之差采用：

`ΔFD = 2w[(mM−mT)(dM+dT)/2 + (dM−dT)(mM+mT)/2]`。

中点差再拆为`(rM0−rT0) + [(mM−rM0)−(mT−rT0)]`。22坐标依次为vx误差/0.2、yaw误差/0.2、vy/0.2、两个重力投影、height误差、16维issued-action减previous-action。权重为1/1/1/6/6/20及每动作坐标0.1/16；对应冻结的vx、yaw、lateral、tilt、height、action_smoothness六组。首拍previous必须使用快照last，command与nominal_height也从原快照读取，保持冻结54的四元数归一化和成本运算。

模型保存了正负端点的六分项成本，但只有**总成本**有AD；因此总AD−FD的162个不同model×point值各被四档真实ε复用，不任意分摊给六项。模型总成本与分项和的舍入、残差坐标重排的舍入、代数恒等式余项分别记录。失败恒等式保留端点、分解数值和失败字段，禁止用原模型的1e−4自检容差掩盖不闭合。

绝对代数量先对22个标量贡献逐坐标取绝对值，再按六成本组求和，保留tilt两坐标和action_smoothness十六坐标内部的抵消信息；有符号分项总贡献另行报告，不混用两种量。

模型±0.001与真实四档ε的差分区间及动作执行精度不同。此处response项是两组有限区间的割线差，不能直接称真实局部Jacobian误差或物理A/B辨识。首拍诊断也不能推出完整长程传播或控制性能已改善；69的所有失败、低幅值及未知参考维持原判。
