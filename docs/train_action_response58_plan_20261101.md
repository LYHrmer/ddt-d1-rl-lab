# 58：训练分布内的一步动作响应标签诊断（执行前登记）

2026-11-01。57 证实了保留集中的局部响应错误，但这些标签不得用于拟合。先确认训练分布能否提供稳定标签，再决定是否训练；本轮不更新任何模型或策略。

1. **假设与唯一变量**：原训练的四条 turn_stop 轨迹在 tick260 也存在稳定负偏航增益，而固定六个 56 模型预测正。以原 53 完整训练 seeds `53103/53106/53109/53112` 的三个时刻 `110/260/410` 共 12 点检验。每点只改变实际输入动作 `a0+δd`；四轮 `d=[+1,−1,+1,−1]`，其余为零，L∞=1、L2=2，没有 θ 残差中的 yaw-error 乘子。
2. **绝对扰动与数据边界**：δ 固定为 `[3.125e−6,6.25e−6,1.25e−5,2.5e−5]`，先在 float64 加到原已裁剪实际动作，再裁剪并转 float32。逐档记录真正执行的动作、差分和 ULP；不能继承 55C 对不同参数化的稳定结论。四条基线含原 σ=.02 动作探索噪声，按原 `default_rng(seed+900000)`、每拍抽一次噪声、调用一次 `real_action` 的顺序复现；分支不重新抽噪声、调用 actor 或推进 shaper。
3. **预算、时长与接口**：先完整复现 4×600=2400 步，逐值核对原训练 NPZ 的全部物理字段；原 episode 索引 2/5/8/11，累计计数单列。live 完整快照只在本拍 `real_action` 后、`env.step` 前捕获，不能冒充策略步起点快照。随后每点两次零分支与四档 ± 一步，共 120 步，总计 **2520 policy /25200 native /12600 PD**；硬 cap3000，CPU300秒、墙钟420秒，预计1–2分钟。复用完整55的224步接口准入，新增准入物理步为0。仅保存快照读回，不落盘12份大体积 raw MjData pickle。
4. **判定规则**：所有基线/分支完整且安全，两次零分支与缓存基线返回状态、观测、reward逐值相同；全部±分支四轮实际动作非零。每点偏航速度28的四档中心差分要求绝对值≥1e−5、同号、全档相对极差≤.25，每档前后向同号且相对差≤.25。全部12点报告；任一点不稳不补挑时刻、不换δ、不重跑。只有四个训练 tick260 均稳定为负且六模型在这些点均稳定预测正，才称本诊断完整复现该训练分布缺陷；否则逐点报告差异。其他七组响应数组和相对RMS也保存，不据此宣称全部45维训练标签合格。
5. **模型比较、资源与后续**：固定六份56完整权重，对全部6×12×4同初态/实际动作输入作一步FD比较，0参数更新，不用保留集标签训练。Nice10、单CPU/线程、MemoryHigh2G/Max3G/Swap0；启动有效内存≥4GiB、运行保留≥2GiB。所有来源前后核验，失败/partial保留且不续跑。即使局部标签可用，也需另登记动作导数监督对照，并通过独立32步梯度与旧点回归；首拍错误并非总代价错误的唯一原因。

七组尺度沿用52 `PHYSICAL_SCALE`。四档响应相对均值及前后向差的RMS分母下限固定1e−8，只防除零，不作新的通过门。源码和输入哈希绑定在 `docs/experiments58/train_action_response58_preregistered.json`。
