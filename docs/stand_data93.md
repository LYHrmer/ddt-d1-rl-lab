# 从同一姿态运行三份策略的 D1 驻坡验证集

原先每份感知 PPO 各配一个起步姿态，发现后溜预测偏差时，无法区分姿态和策略的作用。现在三份冻结策略分别从三个相同的坡上初态出发，每格都有原动作与轮速修正两臂。**首秒后溜的预测偏差随初态翻转。** 重置 90101 上，换任何一份策略，三份世界模型都高估后溜。重置 90102 和 90103 上，所有对应预测都低估。验证集现有 18 条完整物理轨迹和可直接加载的数据包。[验证数据 NPZ](../reports/stand_data93_validation.npz) · [全部九组视频](assets/stand_data93.mp4) · [预注册](experiments93/stand_data.json)

## 训练数据缺哪一段，是否该改课程

重新核对了第 91 轮实际用过的 42 个已结束回合和 11,472 个合法八拍窗口，包含四个提前终止回合。六个坡上起步回合只有 252 个窗口完全位于零指令阶段，其中仅 5 个在源状态到第八个目标的九个端点都保持四轮承重，且五个窗口来自同一回合。承重按同一原生端点记录判定，每轮在坡脚及其后方有超过 1 N 的法向接触。窗口只在同一回合内构造。[训练窗口索引和掩码](../reports/stand_data93_coverage.json)

在末端为第 33～50 拍的窗口里，训练数据的持续四轮承重是 **0/108**，验证数据却有 **99/324**。其中原动作 52/162，轮速修正 47/162。这些窗口彼此重叠。同一条验证轨迹在两种承重条件下的八拍位移增量误差也做了配对比较。按重置汇总，“持续四轮承重减去其他承重条件”的绝对误差中位数差分别为 **+0.0833、−0.3146、−0.0034 mm**，九格都可比较，只有一个重置的差值为正。[事前判定与定义](experiments93/stand_data.json) · [逐格误差](../reports/stand_data93.json)

**本轮补齐了评估对照。后续采集应增加独立的坡上初态，记录复位到首拍的转移，并覆盖首秒后段的持续承重。** 旧训练窗口里缺失该类样本，单纯加权无法补齐。在本次三种初态上，持续四轮承重也没有一致地带来更大的预测误差，因此沿用现有采样权重、策略和奖励。18 条验证轨迹按重置整组留出，避免将同一初态的一条臂用于拟合、另一条臂用于验收。[覆盖与分组审计](../tools93/coverage93.py)

## 直接使用验证数据

下载的压缩包为 643,720 字节。每条轨迹提供 51 个 45 维实测状态（含复位时刻）、50 个 16 维已施加动作及 50 个四轮承重掩码。另含原策略输出、发出动作、实际轮速、轮速目标、力矩、俯仰和决策时可用的延迟测距。区间第 `j` 拍用 `applied16[i,j]` 从 `state45[i,j]` 到 `state45[i,j+1]`，该区间末端的承重为 `support_mask[i,j]`。三个重置是三个分组，每组含三份父策略和两臂。[数据包](../reports/stand_data93_validation.npz) · [数组形状、单位、源哈希及分组](../reports/stand_data93.json)

```python
import numpy as np

with np.load("reports/stand_data93_validation.npz", allow_pickle=False) as data:
    selected = (data["parent_seed"] == 87011) & (data["reset_seed"] == 90102) & (data["arm"] == "common")
    i = np.flatnonzero(selected).item()
    states = data["state45"][i]
    applied = data["applied16"][i]
    source_states, target_states = states[:-1], states[1:]
```

每个原始轨迹和公开数组都保留了 SHA256，桌面视频与仓库副本逐字节相同。补采消耗 600 个策略步、3,000 次伺服更新、6,000 个物理子步。再用三份冻结世界模型完成 36 条新预测、1,800 个模型步，复用 18 条旧预测。策略和世界模型的参数更新均为零。采集、推演和软件离屏编码分开串行运行，单核、Nice 10、MemoryHigh 2 GiB、MemoryMax 3 GiB、swap 0。原生采集单元准入 7.89 GiB，运行最低 7.01 GiB，峰值 0.94 GiB。[资源与计数](../reports/stand_data93.json) · [数据包读回](../tests/test_dataset93.py) · [计分与视频独立读回](../tests/test_public93.py)
