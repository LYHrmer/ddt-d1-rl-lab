本章状态：MuJoCo 3.3.0静态检查通过，未运行地形穿越。场景是明确尺寸的自建测试场，不是从同事录屏精确恢复的原场地。机器人模型、原ONNX、原scene.xml和旧实验保持。

## 启动丰富场景

打开第一个终端，完整复制这一行：

```bash
rtk proxy /home/lyh/ddt_ros2_ws/run_d1_training_course.sh
```

这是现有ROS2/C++运行器，加载同事原配ONNX，不是新训练模型。预期看到原生MuJoCo窗口、分区场地，以及launch日志中controller激活；初始状态是idle。脚本统一设置ROS_DOMAIN_ID=84与本地通信。

第二个终端运行：

```bash
rtk proxy /home/lyh/ddt_ros2_ws/run_d1_keyboard.sh
```

保持键盘焦点在第二个终端。按`7`站起，等待约10秒，再按`1`进入`flat_lab`。以第一个终端的`FSM state changed ... rl_flat_lab`为实际状态依据；键盘界面的状态文字只表示最近请求。

| 按键 | 原配键盘行为 |
|---|---|
| `w` / `s` | 增加 / 减少前向速度请求 |
| `a` / `d` | 增加 / 减少转向角速度请求 |
| 左/右箭头 | 改变侧向请求；持续侧移尚未验证有效 |
| `r` | 全部速度请求清零 |
| `8` | 退出RL并执行下蹲 |

速度请求按次累加，松键不会清零。先在中央平地操作并观察实际运动；不要把键盘显示的请求速度当实测速度。原键盘提示的jump不表示当前D1已实现跳跃。

正常在平地收尾：`r`清零，等停稳后`8`下蹲，随后两个终端分别Ctrl+C。跨在障碍上时下蹲并未验证为安全恢复动作；关闭仿真也不能当作机器人学会自救。

## 参数在哪里

源配置是 `tools/course03_layout.json`，生成器是 `tools/generate_training_course.py`。配置记录seed、位置、长度、坡度、级高、起伏幅度、门净宽。输出在：

```text
src/ddt_ros2_control/urdfs/d1_description/mujoco/
  scene_training_course_03.xml
  training_course_03_assets/
    layout_manifest.json
    rough_10mm.png
    rough_25mm.png
    rough_50mm.png
```

本机已经生成，无需重新执行生成器。自己在干净副本首次生成时运行：

```bash
rtk proxy /home/lyh/ddt_ros2_ws/run_training03.sh /home/lyh/ddt_ros2_ws/tools/generate_training_course.py
rtk proxy cmake --install /home/lyh/ddt_ros2_ws/build/d1_description
```

若输出已存在，生成器会明确拒绝覆盖。这不是故障；要做自己的参数变体，应复制JSON并同时修改`scene_name`与`asset_directory`为新名字，用`--config 新配置路径`生成，安装后以`run_d1_mujoco.sh scene:=新文件.xml`启动。不要修改原实验引用的场景来复用旧成功标签。


本轮实际回执在 `evidence/terrain_course_03/static_validation.json`：MuJoCo3.3.0的12项检查通过；坡面端点/接缝最大误差4.34e−7m；出生点最近障碍边缘距原点约3.4m；20m直道无碰撞障碍；全部标线关闭碰撞。校验没有调用mj_step。

它证明资产几何满足设计，未证明RL能走过。策略通过需要另行冻结命令、预算与门槛，并记录四轮接触、全车包络和停车状态。已有合同02平面对照FAIL保留，不因为场地增加而改判。

## 常见问题

- **文件找不到**：先确认整行路径未被手工断成两行，并执行上面的CMake安装命令；符号链接安装依赖原src和build，不能随意删除。
- **站着不走**：查看实际FSM日志，确认已按7等待站起后按1；按键发给键盘终端，不是MuJoCo窗口。
- **松开还在走**：这是累加请求模式，按r清零。
- **看不到新增场地**：确认用的是`run_d1_training_course.sh`，或显式传入`scene:=scene_training_course_03.xml`。
- **控制异常/重复节点**：不要并行打开两套仿真，也不要让自动测试程序与键盘同时发令。
- **生成器报已存在**：使用新的场景/资产名字；保留原文件和回执。

本章练习：自己从JSON算出6°坡道的高度（1.55×tan6°），在manifest核对；解释为什么0.30m长的15mm箱体与合同02的3m长台面不是同一个越障工况。
