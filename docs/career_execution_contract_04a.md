## 2. 唯一可证伪假设

> **假设**：03b/03c/03d 失败的"停车位移"门槛之所以跨三个版本都未过，是因为奖励中**不存在任何位移/积分项**（F1），而唯一的近零速信号 `standstill_tracking` 在刹车段数值为零、在零速处梯度也为零（F10）。为零命令段加入一个**对"离开该段起点的距离"的惩罚**，可在相同训练预算内同时压低刹车过冲（F6 P1）、消除停住后的再加速（F6 P2）与尾部蠕动（F5），因为它是唯一在整个失败区间内都有梯度、且其量纲就是被考核量的项。

选择它而非"罚零令时轮动作幅值"的理由：F9 表明策略需要**使用**大的负轮速目标才能把刹停距离从 0.036 m 压到 0.006 m；幅值惩罚会同时禁止这件事。位置锚定只约束结果，不规定控制策略。

**不预测、不声称的事项（写在前面以免事后包装）**：

- 本合同**不预期达到 3/3**。turn_stop 同时被两个独立指标卡住（位移 0.0604 m 与 wz MAE 0.1029 rad/s）；本改动对非零转向命令期间**完全不起作用**，不预测修复 wz 增益（F11）。
- 不声称修复 4–8 s 倒退跟踪缺口、`FL_calf` 钳位、地形通过、持续侧移或 1.5 m/s。
- 回报上涨、数值一致、训练 COMPLETE、没有跌倒，**均不等于控制资格通过**。

## 3. 冻结的唯一改动

新增 `training/d1_rl/task04a.py`、`training/configs/pilot04a.json`、`training/d1_rl/factory04.py`。**03d 的命令调度、奖励既有项与权重/尺度、actor 接口与历史、观测、动作尺度与限幅、时基、reset、termination、PPO 网络/优化器/探索参数全部不变。** 不引入 teacher、行为克隆、旧权重热启动、真值线速度 actor 输入、PID 补位或动作后处理。

新增项定义（仅在 `interval_command` 的 vx 与 wz **同时**为 0 时生效，与既有 `standstill_tracking` 的门控条件逐字相同）：

```
anchor_xy := 该零命令段第一个 policy interval 开始时的基座 XY
d         := ‖当前基座 XY − anchor_xy‖
raw(d)    = d² / knee          , d ≤ knee          (knee = 0.05 m)
          = 2d − knee          , knee < d ≤ cap    (cap  = 0.10 m)
          = 2·cap − knee       , d > cap           (= 0.15)
贡献/秒    = raw(d) × weight    , weight = −20.0
```

设计理由：

- `knee = 0.05 m` 取**门槛本身**，门槛以内二次、以外线性，使整个已观测失败区间（0.0163–0.1466 m）都有满梯度，而不像 Gaussian 那样在两端熄灭。
- knee 处值与斜率连续（`raw(knee) = knee`，两侧斜率均为 2），已静态验证。
- `cap = 0.10 m` 使最坏惩罚为 **3.00 /s**，低于零令时的正向底板（`vx_tracking + wz_tracking + alive ≈ 4.25 /s`），**避免出现"主动跌倒结束 episode 比站着漂移更划算"的反向激励**；该不等式已列为静态检查项。

实测形状（静态回执 `anchor_penalty_table`）：

| d (m) | 0.005 | 0.0195 | 0.05 | 0.0604 | 0.0806 | ≥0.10 |
|---|---:|---:|---:|---:|---:|---:|
| 贡献/秒 | −0.010 | −0.152 | **−1.000** | −1.416 | −2.224 | **−3.000** |

训练入口为 `tools04/train_d1_ppo04.py`：它**不复制也不修改**冻结的 `tools/train_d1_ppo.py`，而是先校验其 SHA256 等于 03d release 记录值，再把 `factory03` 的两个查找函数替换为 `factory04` 版本，并以 `runpy` 将冻结训练器作为 `__main__` 执行。因此全部超参、预算上限、计数器、source snapshot 与回执仍由冻结训练器产生。
