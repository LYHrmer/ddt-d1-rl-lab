# 55C：物理差分的局部收敛审查（执行前登记）

日期：2026-11-01。55、55B 的原始输出及原判定保持不变。本轮只诊断物理参考，不训练模型、不选择控制参数、不重判 55。

55B 的两个不稳定点在 ε=0.00025 时单侧差分已接近，但这一个步长不足以证明存在稳定导数。待区分的假设依次为：① 大扰动越过局部接触/求解边界，小邻域可收敛；② 更小动作被 float32 量化，产生虚假稳定或符号波动；③ 更小邻域仍存在求解/接触分支变化。求解器配置和迭代数只作观测，不修改仿真器。

1. **假设与唯一变量**：固定原策略、模型、环境、种子和 32 步代价，仅将物理中心差分的 ε 固定为 `[0.00003125, 0.0000625, 0.000125, 0.00025]`。报告全部四档，不选最有利步长。
2. **预算与时长**：在全新环境重采 55301/55302/55303 各 600 步；每个种子的 110/260/410 点跑两次零分支及四档 ±ε，共 90 条 32 步分支。总计 4680 policy / 46800 native / 23400 PD，policy 硬上限 5000；CPU 300 秒、外部墙钟 420 秒，预计 1–2 分钟。零训练更新，原始工件上限 128 MiB。
3. **判定规则**：三条完整基线与 55 的状态、动作、命令、终止字段逐值相同；每点两次零分支逐值相同；所有分支完整且无跌倒/非法接触。局部参考稳定要求四档中心差分均满足绝对值 ≥1e-5、同号、全档极差 ≤0.25×最大绝对值；每档前/后向差分同号且差距 ≤0.25×二者最大绝对值。全部九点逐一公开，失败点不剔除。本判定只说明这个局部网格内是否稳定，不证明无限小极限存在。
4. **量化与审计**：用 float64 对原始物理状态及实际动作重新计算代价；保留每个 ±ε 首拍四轮实际动作增量及 float32 ULP 比、非零轮数，四轮均非零作为动作扰动可见性的 admission。保存完整分支、策略步接触表/约束数、可用的求解器迭代数与原模型求解器配置。没有原生子步接触表，不能将策略步相关性写成唯一因果。
5. **资源与后续**：单个 systemd 单元 Nice10、单核单线程、MemoryHigh=2G/Max=3G/Swap=0；启动有效可用内存至少 4 GiB、运行保留至少 2 GiB。失败和 partial 不覆盖、不续跑；全部源码与输入执行前后校验。只有物理参考足以判读时才考虑新的、独立登记的训练跨度对照；55 的未通过及控制对照 NOT_RUN 永远保留。

程序、输入和本计划的 SHA-256 见 `docs/experiments55/physical_fd55c_preregistered.json`。本轮不改变 48、冻结源或 runtime v27。
