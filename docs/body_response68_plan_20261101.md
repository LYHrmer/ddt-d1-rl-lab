# 68：训练集前向/侧向动作响应标签的只读准入

67发现真实基点上的首拍前向、侧向代价响应仍可反号。现有64辅助项只监督yaw-rate，因此先判断原训练资料能否提供可靠的body-vx/vy响应标签；不把已诊断的643xx测试点加入训练，也不预先假定增加两个输出能解决长时域偏航幅值错误。

1. **假设**：原58与62训练分支包含足够稳定的body-vx/vy动作响应。**唯一变量**：同一完整物理分支的只读输出坐标，从yaw-rate扩展为body-vx/vy；不改变动作、轨迹或采样点。**预算**：两份来源各12状态、每状态全部4档绝对动作ε，共24状态、96行双通道标签、48个“状态×通道”资格。**判定**：保留全部来源、正负与近零值，不选seed、点或ε。**预计时长**：读取约1–3秒。
2. **假设**：刚体坐标变换和差分顺序可避免人为的小梯度消失。**唯一变量**同上。**预算**：每状态10条原分支（两条零、四组±）；用冻结54的四元数归一化和逆旋转定义计算真实post-state body-vx/vy。**判定**：端点保持F64，先坐标变换再做F64中央和单侧差分；实际动作方向沿用F32执行动作提升F64后差分的v。旧yaw标签逐值恢复，公共pre-state、重复零分支和原始SHA必须一致。**预计时长**：约1秒。
3. **假设**：全部所需标签合格才足以支持这个完整辅助目标的对照。**唯一变量**不增加。**预算**：全部48个状态×通道逐一使用58已有标量稳定规则。**判定**：四档中央差分均同号且绝对值≥1e−5、整网格相对极差≤0.25，每档单侧同号且相对差≤0.25；48/48才为ADMITTED。任何未通过项均保留，诊断完整时仍可为COMPLETE，但训练准入为REJECTED_INCOMPLETE_BODY_RESPONSE_QUALIFICATION，不筛掉标签或放宽门槛。**预计时长**：不足1秒。
4. **假设**：合格的训练标签可以支持一个明确、单变量的后续训练问题。**唯一变量**仍未实施。**预算**：本轮0模型拟合、0actor求值、0物理步、0参数更新。**判定**：只有准入成功，才另行预注册三seed配对：原Lstate＋λLyaw不变，仅新增固定权重的body-vxy JVP辅助项；不把三个输出合并平均而减小yaw权重。该目标是φ(model post-state)的复合输出导数，不宣称纯B修复；新独立测试轨迹与旧回归必须分开。**预计时长**：后续计划审查数分钟，训练预算另计。

固定训练seed为53103、53106、53109、53112，tick为110、260、410；绝对动作ε为3.125e−6、6.25e−6、1.25e−5、2.5e−5，无yaw-error乘子。两来源共24个不同状态、仅4个训练seed，四个ε不是独立样本。原58/62的yaw资格和62原覆盖假设REJECTED保持，不以新增坐标改判。

运行CPU60秒、墙钟120秒；systemd Nice10，单CPU单线程，MemoryHigh2G、MemoryMax3G、Swap0；启动有效可用≥4GiB稳定10秒、运行保留≥2GiB。不停止用户程序，重任务串行；失败和partial独占保留，不覆盖、不重跑、不续跑。源码/输入执行前绑定，执行后复核并冻结执行源码。冻结源、48归档、v27保持。
