# 原厂全身策略在 1.5 m/s 平地验收中的表现

三次 MuJoCo 闭环均行驶满 12 秒，四轮没有触及限矩，均安全停车。第三个起点在车道内跑完，但中央三米均速超过 1.575 m/s 上限。前两个起点速度合格，左前、左后轮驶出车道。完整通过 **0/3**。按事先登记的规则，速度倍率校正、地形开发与盲测均运行 0 段。[预注册门槛](speed110_proposal.md)

车道半宽为 1 m。前两个起点的机身在 x=7 m 处分别向左偏约 0.81 m、0.79 m，左轮偏得更远。给策略的偏航角速度指令全程为零；角速度回到零时，已经积累的航向误差仍会让车继续斜行。可以在三个新起点上单独检验 IMU 航向反馈能否修复这项失败。

这轮使用厂家随 D1 提供的 `flat.onnx`，策略及世界模型各更新 0 次。共执行 1,800 次策略决策、9,000 次伺服更新、18,000 个物理子步。第一次静态预检在浮点力矩等价性检查处结束，未步进物理。统一换算精度后另开预检，最大力矩换算误差为 0，四种几何各通过 14 次静态射线核对。[完整轨迹、资源记录与失败回执](../reports/speed110/results.json) · [复算入口](../tools110/readback.py)
