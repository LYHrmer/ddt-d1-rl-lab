# D1 坡上起步时，世界模型给全身策略的一步更新能否减少后溜？

1. **复核已保存的轮速试验。** 假设是模型能判断四轮目标同步增减的后果。唯一变量为共同轮速偏置，使用已经保存的 ±0.10 和 ±0.20 rad/s。预算为 36 条原生曲线及对应模型曲线，新增仿真、模型调用和训练均为零。主读数取全部原生轨迹都在首次接地终止前的最后一拍（第 30 拍，0.60 秒），检查两种半径的回报差是否同号、相对误差是否在 25% 内。第 32 拍另核查模型的自动微分、模型自身差分和原生差分。所有时窗和种子都保留。预计 10～15 分钟。
2. **验证整张策略网络的更新方向，需另行批准。** 假设是按模型建议微调一次腿和轮的策略参数，可以让机器人在坡上起步时更接近驻车点。唯一变量是沿预先算好的参数改变量 `d` 走多远，取 −1、−0.5、0、+0.5、+1 倍。沿用三份冷启动初始策略和各自完整拟合的第一轮模型，每个只使用本种子编号最前的三个训练回合的复位状态计算 `d`。保持原 H32 平均驻车偏离回报、首次 Adam 的学习率 0.0003 及梯度范数上限 1。只取复位时刻，检验范围限于起步。方向及输入哈希在查看新原生结果前封存。

   三个新复位种子为 95101、95102、95103，每份策略各测一遍。三模型 × 三起点 × 五个步幅，共 45 段，每段最多 32 个 50 Hz 决策（0.64 秒），合计最多 1,440 个原生决策、7,200 次伺服、14,400 个物理子步和 1,728 个学习模型步。最多 3 次构造方向的反向传播、9 次验证起点的反向传播。检查点不更新，世界模型拟合及正式策略训练预算均为零。单 CPU、单环境串行，沿用 Nice 10、2/3 GiB 内存软硬上限、零交换及启停内存水位。

   原生回报定义为各拍机身沿世界 x 轴偏离复位点的绝对值取平均后加负号，以米计。每个起点五臂都须跑全且无跌倒/非法接触。两种半径的原生中心差分均须为正、彼此相差不超过 25%，且各自与该起点模型的解析方向导数同号、相差不超过 25%。模型自己的两档差分另与解析导数核对。两个正向步幅的实测回报各须优于零步幅。比较统一使用两数绝对值的较大者作相对误差分母，零变化不算改善。九组均满足才能称此方向在这些起点通过。早停、异常和缺测原样登记，禁止补拍、补种子或改门槛。预计接线、运行及核验 45～90 分钟。
