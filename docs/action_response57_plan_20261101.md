# 57：从保存轨迹区分动作响应与基线偏差（执行前登记）

2026-11-01。56 完整对照显示状态拟合更准而方向仍反号。本轮只定位机制，不训练、不新增物理步，不改变 53/55/56 的结论，也不把 oracle 校正当作模型修复。

1. **假设与范围**：依次检验首拍局部动作响应偏差、代价线性化位置偏差、后续轨迹及敏感度传播偏差。固定 56 的六个模型、全部新九点与四档 ε；54 个模型/点组合全部报告，不挑失败点或最有利步长。
2. **同输入响应读回**：使用 56 保存的实际 float32 `a±`，在同一真实初态直接调用模型，与真实首拍状态中心差分比较。随后每拍分别输入真实 `s±` 和实际 `a±`，比较模型下一状态差分与真实下一状态差分。唯一替换是单步转移算子（真实保存转移或学习模型），观测、动作、ε 相同。全 32×45 数组及七组尺度化 RMS 误差保留；首拍偏航响应给出真实值/模型值。后续比较包含状态和动作同时扰动，不能独立归因于动作 Jacobian。
3. **两项分层 oracle**：先精确复现 56 的自由梯度；第一项只将 cost 的基点移到真实 θ=0 状态/动作，保留自由展开导数链；第二项复用 55 的观测轨迹前向校正，沿原模型局部导数反向。各项保持模型 ε=.001、原自检容差和幅值门。逐项只换一个接口，分别计方向；如果 oracle 纠正符号，只支持其所改变的基点/传播位置参与偏差，不能宣称模型 Jacobian 正确或已修复自由预测。
4. **预算与判读**：0 物理步、0 模型更新、0 策略更新；CPU 300 秒、外部墙钟 420 秒，预计 1–3 分钟。四档逐项响应误差只作诊断，不新增合格阈值、选择 ε 或重判旧试验。只有原自检通过的 oracle 梯度才计有效同号；首拍符号吻合只排除该首拍的简单方向颠倒，不能排除幅值、后续状态 Jacobian 或反馈传播错误。
5. **资源与留档**：Nice10、单 CPU/单线程、MemoryHigh2G/Max3G/Swap0；启动有效可用内存 ≥4 GiB，运行保留 ≥2 GiB。输入为完整 56 的快照、90 个分支 NPZ、六份最终权重及报告，SHA 执行前后验证，原始数据只读。输出逐点 JSON/NPZ，失败及 partial 全留，不覆盖/续跑。完成诊断后再决定是否需要新的动作响应监督候选。
