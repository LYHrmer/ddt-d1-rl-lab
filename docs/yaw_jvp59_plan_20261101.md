# 59：动作方向导数监督的三对初始化验证（执行前登记）

2026-11-01。58 的“训练 tick260 全负”假设仍被否定；本轮的新问题是：对全部12个已稳定的训练状态加入偏航响应导数监督，能否修复独立轨迹上的局部响应和闭环梯度？不挑其中两个负点、不使用保留集标签拟合。

1. **唯一变量与配对**：模型保持原 H8、相同7200条训练转移、6828个共同32步窗口、1000×64采样、结构、ridge/归一化、Adam3e−4及clip1。seeds固定59001/59002/59003，各有 `state_only` 和 `state_plus_yaw_jvp`。状态损失 S 是原七组H8误差；新增 R 为全部12状态×4尺度上 `mean(((J_a F(s,a0)[28]·v − true_FD[28])/.3)^2)`。v由保存实际a±在F64中相减除2δ形成后转F32，目标也先在F64求差分再转F32；不单位化、不乘yaw error。48行不是48个独立状态。
2. **权重、计算与预算**：初始共享ridge与零残差输出下，S0取全部6828窗口的H8损失均值，末批44窗口按实际数量加权；R0取全部48标签。λ=`float(S0/R0)`只在更新前计算一次、脱图封存，要求S0/R0/λ均有限且正，三seed初始函数/JVP和λ一致。两臂均每次计算全部48个JVP并保留参数混合二阶导，唯一区别为有效λ=0或该固定值。它只平衡初始损失贡献，不平衡梯度强度。六模型各1000次更新，共6000更新；零新增物理训练数据、零策略或控制参数更新。CPU硬限600秒、外部墙钟900秒，预计3–6分钟；超限留partial、不补跑。
3. **自由闭环验证**：全部六fit及数据/标签/窗口/采样/初始化/ridge/λ配对身份先核验。旧53开发九点只作数值回归；旧53探针、55C、56及新59301/59302/59303各九点作四组真实方向核验。新三条完整基线各600步，110/260/410取点，预测先封存，再跑固定四档ε=.00003125/.0000625/.000125/.00025及两zero，共90×32分支；合计4680 policy/46800 native/23400 PD，cap5000，复用55已有接口准入而不新增224步。所有梯度均自由展开，不输入真实未来轨迹校正。保留模型ε=.001、原自检容差和幅值门；active三个模型必须各自四组36点全部有效同号。旧53的较大两档FD只是历史回归，不能称其无穷小导数已验证。
4. **局部响应与判定层次**：另对旧56及新593xx两组共18点，用保存的同初态/实际a±验证首拍yaw28。真实四档中心/单侧差分沿用同号、幅值≥1e−5、全档极差及每档单侧差均≤25%的规则；模型每档响应幅值≥1e−5且全部同号。active三模型须各自18点×4尺度全通过，防止总代价误差抵消掩盖局部反号。参考不可判、active绝对门及配对优越性分开：任一必需参考未定标 `REFERENCE_UNRESOLVED`，不算模型错；对照自检失败仅使配对收益不可判。两臂自检合格时，只有每seed的36点cost有效数与18点首拍有效数都不下降，且至少一项严格增加，才支持本次固定配对收益。两臂皆通过则不自动声称辅助损失收益。逐seed/逐组完整报告状态误差，不新增临时loss门。
5. **资源与交付边界**：所有本机数值/物理任务串行，Nice10、单CPU/线程、MemoryHigh2G/Max3G/Swap0，启动有效可用内存≥4GiB、运行保留≥2GiB。不停止其他程序；全部失败/partial保留、不覆盖/续跑，只用第1000次最终权重，不选best seed/checkpoint。源码、数据、λ、封存预测及最终权重前后核验。通过只支持本轮离线响应与梯度候选，未运行控制性能对照，不能宣称运控性能提升或替换默认模型。

额外观察项（执行前固定，不是通过门）：每个最终模型在全部48条训练标签上输出最终CPU F32 yaw JVP、目标、方向及幅值匹配和按0.3尺度归一化RMSE，用于区分辅助损失未拟合与拟合后未泛化。只诊断第1000次最终权重，不更新、不选模型。
